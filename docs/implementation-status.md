# Implementation Status

This page separates released artifacts, code on `main`, optional runtime modes, and deployment-specific qualification. This change set started from `main` at `59331d09` on 2026-08-31; its main-only rows become true of `main` only after this pull request merges.

## Version boundary

The latest published release is [`v0.7.0`](https://github.com/AdrielC/graviton/releases/tag/v0.7.0). Its release workflow completed successfully, and its 15 library modules are available from Maven Central. The server, CLI, and browser applications are runnable deliverables, not Maven library artifacts.

Current `main` contains additional work after `v0.7.0`. In particular, multi-tenant hardening, Redis or Valkey distributed admission, GVM4 metadata and manifest authentication, the operator control plane, and Production Qualification and Telemetry v1 are implemented and tested in the repository but are not part of the `v0.7.0` jars. Use a source build until a later release explicitly includes them.

Status terms used below:

- **Released in v0.7.0** means the implementation is present in the signed Maven Central release or its corresponding runnable release assets.
- **Implemented on main** means source and executable tests exist on `main`, but the change postdates `v0.7.0`.
- **Optional on main** means the implementation is mounted only when its configuration is enabled.
- **Target qualification required** means repository proof exists, but a provider, topology, capacity, or failure claim must be established in the operator's environment.
- **Not shipped** means there is no supported module or runtime path.

## What production qualification still means

Repository tests establish behavior on their exact fixtures and runners. They do not establish a universal customer count, throughput envelope, recovery objective, provider service level, or security posture. Before customer traffic, run the target-only gates against the exact image digest, region, account, instance sizes, IdP, ingress, PostgreSQL or RDS mode, S3 or Ceph service, and Redis or Valkey topology.
