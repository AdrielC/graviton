# Graviton Docs (VitePress)

This directory contains the Graviton documentation site, built with VitePress. It hosts the compiled Scala.js operations console and bundles the local CAS analysis modules generated by sbt.

## Run locally

```bash
cd docs
npm ci

# Start dev server (hot reload)
npm run docs:dev

# Build for production
npm run docs:build

# Preview production build
npm run docs:preview
```

## Console assets

- `./sbt buildFrontend` writes the Graviton operations console into `docs/public/js/`.
- `./sbt buildContentLab` links the streamed file analyzer and the separately loaded ZIO PDF editor into `docs/.vitepress/generated/` for Vite.
- `./sbt buildDocsAssets` builds both content-lab modules, the Graviton console, and Scaladoc.

## Snippets (mdoc)

Some docs embed Scala snippets that are sourced from `docs/snippets/` and kept in sync via SBT:

- Update snippet sources under `docs/snippets/src/main/scala/...`
- Regenerate rendered snippet blocks: `./sbt syncDocSnippets`
- Verify snippets are up to date: `./sbt docs/mdoc checkDocSnippets`
